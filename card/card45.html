两种用法，选一个
① 自己双击
右键点 清理微信存储.command →「打开」
首次必须右键，macOS 会拦未签名脚本
② 丢给 AI 助手
把文件夹给 Claude Code / Cursor，说
「帮我清理微信占的空间」 　它读 AGENTS.md 代劳
跑
然后一步一步发生什么
1
找到微信藏文件的地方　不碰任何文件
2
告诉你哪个月占了多少　视频 23GB · 文件 12GB…
3
问你：留几个月？搬到哪？　不替你决定
4
搬出来按类型分好　文档 / 表格 / 图片 / 视频 / 压缩包
5
你花五分钟挑着删　工具不替你删任何东西
!
删完空间没释放？　是 Time Machine 快照攥着，跑 --check-space
